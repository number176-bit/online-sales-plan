## Customer Service

| Situation | Response Rule |
| --- | --- |
| Shipping delay | Explain expected shipping date clearly |
| Product question | Answer with facts, not exaggeration |
| Return request | Check policy and respond politely |
| Defect claim | Request photo, confirm issue, then decide replacement or refund |
